This module restricts some payment methods to POS managers, for example
a manual card payment method used when the payment terminal is out of
order.

**Table of contents**

.. contents::
   :local:

Configuration
=============

Go to *Point of Sale > Configuration > Payment Methods* and check
*Manager Only* on the payment methods reserved to managers.

This option can be changed while a session is open. Reload the POS to
apply it.

Usage
=====

In the POS, these payment methods are only displayed to managers: users
of the *Point of Sale / Administrator* group or, when employees are
enabled on the POS, employees with advanced rights.

When employees are enabled, a manager can log in on the register with
their PIN code to use such a payment method on the current order. The
order keeps the employee who created it. An order paid with such a
payment method can only be validated by a manager.
